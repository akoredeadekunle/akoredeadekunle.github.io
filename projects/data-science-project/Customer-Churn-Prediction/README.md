# Customer Churn Prediction & Retention Analytics

## Overview

An end-to-end machine learning project that analyzes customer behavior
and predicts customers who are at risk of churning from a
telecommunications company.

The project combines exploratory data analysis, feature engineering,
classification modeling, model evaluation, hyperparameter tuning, and
customer risk segmentation.

## Business Problem

Customer churn can negatively impact revenue and increase customer
acquisition costs.

The objective of this project is to identify patterns associated with
customer churn and develop a machine learning solution that can help
businesses identify high-risk customers and support proactive retention
strategies.

## Objectives

- Analyze customer churn patterns.
- Identify factors associated with customer churn.
- Develop multiple classification models.
- Compare model performance.
- Optimize the strongest model.
- Predict customer churn probability.
- Segment customers according to churn risk.
- Provide actionable business recommendations.

## Machine Learning Models

- Logistic Regression
- Decision Tree
- Random Forest
- Tuned Random Forest

## Project Workflow

Data Collection → Data Cleaning → Exploratory Data Analysis →
Feature Engineering → Model Development → Model Evaluation →
Hyperparameter Tuning → Risk Prediction → Business Recommendations
