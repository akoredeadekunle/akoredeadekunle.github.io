# Power BI Sales Dashboard

## 📊 Project Overview

This project is an interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance, customer behavior, product performance, and overall business trends.

The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, KPIs, filters, and data analysis.

## 🎯 Project Objectives

- Analyze overall sales performance
- Track monthly sales trends
- Identify top-performing products
- Analyze customer performance
- Monitor key sales KPIs
- Identify trends and patterns that can support business decision-making

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

## 📈 Dashboard Analysis

The dashboard provides insights into:

- Total Sales
- Total Customers
- Average Sales per Customer
- Monthly Sales Trends
- Top 10 Products
- Customer Performance
- Product Performance
- Sales Trends and Patterns

## 💡 Key Skills Demonstrated

- Data cleaning and transformation
- Data modeling
- DAX calculations
- KPI development
- Interactive dashboard design
- Business data analysis
- Data visualization
- Insight generation
